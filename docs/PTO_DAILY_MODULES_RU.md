# Ежедневные инструменты инженера ПТО

## Новые разделы в Open Field Studio

В русскую вкладку «АОСР · КС-2» добавлена секция «Ежедневные документы инженера ПТО» с тремя реестрами и контрольной таблицей.

1. **Журнал общих работ (ОЖР):** дата записи, номер связанного акта, описание и номер страницы/записи. Выявляются неверные даты и записи за пределами периода работ, но параллельные работы допустимы.
2. **Материалы и документы качества:** номер акта, тип и номер паспорта/сертификата/декларации, материал, срок действия и имя локального файла. Данные требуют документального подтверждения.
3. **Исполнительные схемы:** номер акта, номер схемы, название, редакция, имя файла. Выявляется конфликт между актом и реестром схем.
4. **Комплектность АОСР:** для каждого акта показываются зарегистрированные связи и недостающие сведения. Замечания можно скачать в CSV.

Реестры необязательны при основном вводе актов. Данные сохраняются в рабочей области браузера, JSON-резервной копии, а при обычном экспорте Excel — в листах «ОЖР», «Документы_качества» и «Реестр_схем». При повторной загрузке книги записи восстанавливаются.

Ввод ссылок не означает наличие, подлинность или юридическое согласование реальных документов. Файлы не копируются и не загружаются в облако — пока сохраняется только их имя. Не отмечайте отсутствие записи как отсутствие самого оригинала.

## Исходные файлы

- src/pto/records.mjs — модели трёх реестров, поиск расхождений и предупреждения.
- src/pto/domain.mjs — ограниченная сериализация в JSON (до 300 записей на реестр).
- src/pto/ui.mjs — ввод, удаление и отчёт о комплектности на русском языке.
- src/pto/xlsx.mjs — экспорт и импорт Excel-реестров.
- tests/pto-records.test.mjs и tests/e2e-pto-records.spec.mjs — автоматические проверки.

**Осталось для следующего этапа:** фактическое хранение вложений и SHA-256, импорт файла общего журнала работ, история версий, согласование с ответственными лицами. Ни один новый статус не является юридическим подтверждением соблюдения требований заказчика или законодательства.
