3. [02 — Прораб, инспектор и сдача объекта](02_Прораб_инспекция_и_сдача.md) — чертежи, замечания, чек-листы, панель управления, сдача.
4. [03 — Роли и план ежедневной работы](03_Роли_и_ежедневные_сценарии.md) — кто и когда вносит данные, кто проверяет, где нужен человек.
5. [04 — Контрольная ведомость приемки пилота](04_Контрольная_ведомость_пилота.md) — тесты, ограничения и критерии эксплуатации.
6. [Технический аудит всей системы](../../docs/audit/WHOLE_SYSTEM_RU_AUDIT.md) и [реестр всех публичных ссылок](../../docs/audit/SOURCE_REGISTER.md).

- [Данные трёх учебных АОСР](examples/Демо_АОСР_рабочие_данные.json) — копия публичного синтетического проекта, без персональных данных.

- [SCREEN_CAPTURE_MANIFEST.json](SCREEN_CAPTURE_MANIFEST.json) — список снимков, версия локали, подписи и ошибки браузера.
- [Скрипт повторного создания скриншотов](scripts/capture-russian-ui.mjs) — локальный Playwright Chromium; запуск из корня репозитория после включения Vite на 127.0.0.1:3042.

**Защита информации:** на всех изображениях вымышленные адрес, организация, фамилии/роли и документы. Исходный файл инженера и реальные паспорта не добавлены в Git. Обычный JSON проекта не содержит байты вложенных файлов: резервировать их нужно отдельно.

**Правовой статус:** АОСР, ОЖР, приложения и файлы ZIP в демонстрации — **черновики**. Нарисованная подпись и SHA-256 не являются УКЭП/УНЭП, заверенным журналом или подтверждением выполнения работ.

### Уточнение российского рынка

Вкладка «Проект» в русской локали теперь показывает **«Проверить адрес в ФИАС / ГАР (вручную)»** вместо нидерландского BAG. Это ссылка на официальный сайт ФНС, **без автоматического подтверждения адреса**. Раздел «Интеграции» помечает зарубежные коннекторы как не проверенные для 1С/Exon/ГРАНД-Сметы. См. скриншоты [31](screenshots/31-project-fias-ru.png) и [32](screenshots/32-connectors-ru-warning.png) и [источники](../../docs/audit/RU_MARKET_UI_REMEDIATION_2026-10-30.md).
